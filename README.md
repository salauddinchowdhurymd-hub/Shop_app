# 🛍️ দোকান অ্যাপ - Bengali Accounting System

সম্পূর্ণ বাংলায় ছোট দোকানের একাউন্টিং ম্যানেজমেন্ট সিস্টেম!

## ✨ প্রধান ফিচার

- 🔐 **নিরাপদ লগইন** - SHA256 এনক্রিপশন সহ
- 📊 **লাইভ ড্যাশবোর্ড** - রিয়েল-টাইম অবস্থা
- 💰 **দৈনন্দিন লেনদেন** - সব ধরনের ক্যাশ ট্রান্সফার
- 🤝 **মহাজন ম্যানেজমেন্ট** - সরবরাহকারীর হিসাব
- 👤 **কাস্টমার বাকি** - ক্রেডিট ট্র্যাকিং
- 🏦 **ওয়ালেট ব্যালেন্স** - একাধিক মাধ্যম সমর্থন
- 📈 **রিপোর্ট ও গ্রাফ** - বিশ্লেষণ ও ভিজুয়ালাইজেশন
- 📥 **ডেটা এক্সপোর্ট** - CSV ডাউনলোড
- ⚙️ **সম্পূর্ণ সেটিংস** - কাস্টমাইজেশন সুবিধা

## 🚀 ইনস্টলেশন ও চালু করা

### প্রয়োজনীয় সফটওয়্যার
- Python ৩.৮+
- pip (Python প্যাকেজ ম্যানেজার)

### ধাপে ধাপে গাইড

```bash
# ১. রিপোজিটরি ক্লোন করুন
git clone https://github.com/salauddinchowdhurymd-hub/Shop_app.git
cd Shop_app

# ২. ভার্চুয়াল এনভায়রনমেন্ট তৈরি করুন (ঐচ্ছিক কিন্তু সুপারিশকৃত)
python -m venv venv
source venv/bin/activate  # Linux/Mac
# বা
venv\Scripts\activate  # Windows

# ৩. প্যাকেজ ইনস্টল করুন
pip install -r requirements.txt

# ৪. অ্যাপ চালু করুন
streamlit run app.py
```

অ্যাপ খুলবে: `http://localhost:8501`

## 🔑 লগইন তথ্য

| দোকানের নাম | পাসওয়ার্ড |
|-----------|----------|

**নিরাপত্তা টিপ:** প্রথমবার লগইনের পর অবশ্যই পাসওয়ার্ড পরিবর্তন করুন!

## 📋 মেনু অপশন বিস্তারিত

### 1. 📊 ড্যাশবোর্ড
- মোট ক্যাশ ইন/আউট দেখুন
- বর্তমান ব্যালেন্স জানুন
- বকেয়া তালিকা চেক করুন
- সাম্প্রতিক লেনদেন দেখুন

### 2. 💰 দৈনন্দিন লেনদেন
- নতুন লেনদেন যোগ করুন
- তারিখ, বিবরণ, পরিমাণ রেকর্ড করুন
- মাধ্যম নির্বাচন করুন (ক্যাশ, ব্যাংক, বিকাশ, নগদ)
- লেনদেন এডিট বা মুছুন

### 3. 🤝 মহাজন হিসাব
- সরবরাহকারীর তথ্য যোগ করুন
- বিল ও পরিশোধ ট্র্যাক করুন
- বকেয়া পাওনা হিসাব করুন
- মহাজন সারসংক্ষেপ দেখুন

### 4. 👤 কাস্টমার বাকি
- গ্রাহক বিক্রয় রেকর্ড করুন
- বাকি পরিমাণ ট্র্যাক করুন
- কাস্টমার তালিকা পরিচালনা করুন
- বাকির হিসাব সারসংক্ষেপ

### 5. 🏦 ওয়ালেট ব্যালেন্স
- প্রতিটি মাধ্যমে ব্যালেন্স দেখুন
- মেথড-ভিত্তিক লেনদেন ফিল্টার করুন
- বিস্তারিত তথ্য প্রাপ্ত করুন

### 6. 📈 রিপোর্ট ও গ্রাফ
- মাসিক আয়/খরচ বিশ্লেষণ
- গ্রাফিক্যাল রিপোর্ট দেখুন
- ডেটা এক্সপোর্ট করুন (CSV)
- প্রিন্টের জন্য প্রস্তুত করুন

### 7. ⚙️ সেটিংস
- পাসওয়ার্ড পরিবর্তন করুন
- ডেটা ম্যানেজমেন্ট
- অ্যাপ তথ্য দেখুন
- সব ডেটা মুছুন (সাবধানে!)

## 💾 ডেটা সংরক্ষণ

সব ডেটা স্থানীয়ভাবে সংরক্ষিত হয়:
- **লেনদেন:** `data/[shop_name]_sales.csv`
- **মহাজন:** `data/[shop_name]_supplier.csv`
- **কাস্টমার:** `data/[shop_name]_customer.csv`
- **ইউজার:** `users.json`

- মহাজন হিসাব

## 🐛 সমস্যা সমাধান

### অ্যাপ খুলছে না?
```bash
pip install --upgrade streamlit
streamlit run app.py
```

### ডেটা পাচ্ছি না?
- `data/` ফোল্ডার থাকে কিনা চেক করুন
- CSV ফাইলের অনুমতি চেক করুন
- `streamlit cache` ক্লিয়ার করুন

### পাসওয়ার্ড ভুলেছেন?
- `users.json` ফাইল মুছে দিন এবং রিস্টার্ট করুন
- নতুন ডিফল্ট অ্যাকাউন্ট পাবেন
